# Водич за дружба со Жејко (TurtleBot 4, ROS 2 Jazzy)

Документ во LaTeX (`pdflatex`, кирилица со `T2A`). Главен фајл: `main.tex`.

## Преземање на проектот првпат (Fedora/Linux)
Ако сè уште ја немаш папката на проектот на компјутерот:

1. Отвори Terminal.
2. Инсталирај Git (ако веќе е инсталиран, ова може да се прескокне):
   ```bash
   sudo dnf install git
   ```
3. Оди во папката Downloads:
   ```bash
   cd ~/Downloads
   ```
4. Преземи го проектот од GitHub:
   ```bash
   git clone https://github.com/TeodorTodorovski01/ZELKA.git
   ```
5. Влези во папката на проектот:
   ```bash
   cd ZELKA
   ```
6. Избери дали сакаш да го изградиш PDF-водичот или да го користиш ROS комплетот за роботот во следните делови.

Ако GitHub побара најава или дозвола, следи ги упатствата што ќе се појават во Terminal или во browser. За подоцнежно преземање на најновите измени, отвори Terminal во папката `ZELKA` и изврши `git pull`.

Ако сакаш само да ги прегледаш фајловите, можеш на GitHub да избереш **Code → Download ZIP** и да ја отпакуваш ZIP-датотеката. За да добиваш измени и да испраќаш свои, користи `git clone` како во чекорите погоре.

## Што има во репото
- `main.tex` – содржина на документот (глави и потсекции)
- `lab_notes.sty` – стил/шаблон (не се менува без договор)
- `logo.png`, `runba.png`, `figures/` – слики
- `arhiva/` – стари/неискористени фајлови (не влегуваат во компајлирањето)
- `zheljko/` – TurtleBot 4 ROS 2 Jazzy комплет: Podman Containerfile build, влезна скрипта и референтни команди. Ова е копија од [оригиналното GitLab репо](https://gitlab.com/asifeit/zheljko); вклучена е `.git`-независно за да работи и при GitHub ZIP-download.

## Користење на ROS комплетот со роботот
Овој дел е посебен од LaTeX/PDF-водичот. Потребен е Linux лаптоп со Podman и пристап до ASI Wi-Fi.

1. Инсталирај Podman ако го немаш:
   - Fedora: `sudo dnf install podman`
   - Ubuntu: `sudo apt update && sudo apt install podman`
2. Поврзи се на ASI Wi-Fi. Провери дека роботот е достапен:
   ```bash
   ping -c 4 192.168.1.110
   ```
   IP-адресата може да се смени; ако ping не успее, провери ја адресата прикажана на роботот и користи ја таа адреса.
3. Отвори Terminal и влези во папката на комплетот. По чекорите за првично преземање погоре:
   ```bash
   cd ~/Downloads/ZELKA/zheljko
   ```
   Ако репото е преземено/отпакувано на друго место, замени ја патеката со вистинската локација.
4. Стартувај го комплетот:
   ```bash
   ./enter.sh
   ```
   При првото стартување се гради ROS 2 Jazzy Podman image и се преземаат околу **1.5 GB**; image-от зафаќа околу **4 GB** на дискот. Почекај да заврши. Следниот пат во секој нов Terminal, повторно изврши `./enter.sh` од папката `zheljko/`.
5. Во контејнерот, провери ја ROS конекцијата со нештетни команди:
   ```bash
   ros2 node list
   ros2 topic echo --once --qos-reliability best_effort --field percentage /battery_state
   ```

`zheljko/commands.txt` ги содржи целосните упатства за статус, сензори, камера, GUI и решавање проблеми. **Внимание:** секцијата 12 во тој фајл содржи команди што го движат роботот. Прво провери дека роботот е оддокуван, просторот околу него е празен и никој друг не управува со него. Секциите 14–20 опишуваат конфигурација и администрирање што влијаат на сите корисници; не менувај ги без дозвола/договор со класот.

Скриптата `zheljko/setup.sh` прави промени само кога експлицитно ќе ја стартуваш (директно или преку првото `./enter.sh`). Нејзините опции, вклучувајќи `--recreate` и `--sim`, се објаснети во `zheljko/README.txt`. `--recreate` го брише постојниот Podman container со име `turtlebox` пред повторно да го создаде; зачувај ги сите важни фајлови надвор од container-от. Вклучените фајлови се snapshot од GitLab, не жив Git submodule; за понови upstream измени треба повторно да се синхронизираат.

## Правила за пишување
- Секоја глава се означува со `\glava{Наслов}{индекс на автор}`, а потсекциите со `\potglava{Наслов}{индекс}`.
- Авторите и нивните индекси се во `\author{...}` и во легендата по `\maketitle` во `main.tex`.
- Пишувај само во своите глави. Пред работа изврши `git pull`. По измените, провери што ќе испратиш со `git status`, додај ги само изменетите фајлови со `git add име-на-фајл`, па изврши `git commit -m "опис"` и `git push`.
- Не додавај `.pdf` и помошни фајлови во репото (`.gitignore` ги игнорира).

## Компајлирање
- Овие чекори се само за PDF-водичот; не се потребни за ROS комплетот во `zheljko/`.
- **Fedora, прво поставување:** инсталирај ги потребните LaTeX пакети (не целиот TeX Live):
  ```bash
  sudo dnf install \
    texlive-scheme-basic \
    texlive-tufte-latex \
    texlive-collection-latexrecommended \
    texlive-collection-langcyrillic \
    texlive-collection-fontsrecommended \
    texlive-extract \
    texlive-multibib \
    texlive-pstricks \
    texlive-sauerj \
    texlive-hardwrap \
    texlive-xifthen
  ```
- **Градење на PDF:** од папката на репото изврши `bash build.sh`. Скриптата го компајлира документот двапати и го зачувува во `build/main.pdf`.
- **VS Code:** инсталирај ја ексензијата *LaTeX Workshop* (препорачана); по инсталирањето на пакетите погоре може да градиш од VS Code.

Ако градењето запре со `File 'име.sty' not found`, недостасува LaTeX пакет. На Fedora најди кој пакет ја содржи датотеката со `dnf provides '*/име.sty'`, инсталирај го со `sudo dnf install име-на-пакет`, па повторно изврши `bash build.sh`.
